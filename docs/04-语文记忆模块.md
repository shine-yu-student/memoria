## 文章管理页面

### 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  文章记忆  共 N 篇                             [＋ 新建文章] │
│──────────────────────────────────────────────────────────────│
│  [🔍 搜索标题…]                             N 篇 / 匹配 M 篇 │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐          │
│  │ 文章标题      │ │ 文章标题      │ │ 文章标题      │          │
│  │ 内容预览……    │ │ 内容预览……    │ │ 内容预览……    │          │
│  │ N 句 · M 字   │ │ N 句 · M 字   │ │ N 句 · M 字   │          │
│  └──────────────┘ └──────────────┘ └──────────────┘          │
└──────────────────────────────────────────────────────────────┘
```

- **页面头部**：`PageShell` 提供标题「文章记忆」、副标题（共 N 篇）与右侧的「＋ 新建文章」按钮。
- **工具栏**：搜索框按标题过滤（不区分大小写），右侧显示总数或「匹配 M / N 篇」。
- **文章容器**：自适应网格（`repeat(auto-fill, minmax(220px, 1fr))`）。
- **文章卡片**：显示标题（最多两行）、内容预览（最多两行）与句数/字数；鼠标悬停时右上角显示 🗑️ 删除按钮。
- **空状态**：没有文章或没有匹配结果时显示 `EmptyState`，无文章时附带「＋ 新建文章」按钮。

### 交互流程

1. 点击「＋ 新建文章」→ 弹出标题输入弹窗（留空则自动命名「未命名文章 N」）→ 创建后直接进入编辑页面。
2. 点击文章卡片（非删除按钮区域）→ 进入编辑页面。
3. 悬停文章卡片 → 右上角显示 🗑️ 删除按钮。
4. 点击删除按钮 → 确认弹窗 → 确认后删除并弹出 Toast。

## 文章编辑页面

### 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│  [←]  [文章标题输入框]                 [⬇️ 导出] [🧠 开始记忆] │
│  共 N 句 · M 字                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  （文本编辑区域，占剩余高度）                            │  │
│  └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

- **返回按钮**：左上角 `←` 图标按钮。
- **文章标题**：`TextField`，可直接修改；标题与正文都采用 **500ms 防抖落盘**，组件卸载前与进入记忆/导出前会强制 flush，避免丢失最后一次输入。
- **操作按钮**：标题右侧为「⬇️ 导出」与「🧠 开始记忆」。
- **元信息行**：显示实时切分出的句数与字数。
- **编辑区域**：占满剩余空间的 textarea，输入即自动重新切分句子。

## 记忆模式选择

点击「开始记忆」后进入模式选择页面，以卡片形式显示三种模式：

```
┌─────────────────────────────────────────────┐
│  📝 全篇记忆                             ›  │
│  不提供任何提示，凭记忆输入整篇文章。          │
├─────────────────────────────────────────────┤
│  📄 部分记忆                             ›  │
│  只记忆文章中部分句子。                      │
├─────────────────────────────────────────────┤
│  🎯 指导记忆                             ›  │
│  按照配置步骤逐步记忆文章，适合初次接触的文言文。│
└─────────────────────────────────────────────┘
```

## 全篇记忆

1. 用户点击「全篇记忆」→ 显示覆盖整篇的文本框（文章为空时以 Toast 提示并拦下）。
2. 用户凭记忆输入整篇文章，标点与换行也需要写出。
3. 点击「提交」→ 进入结果页。
4. 结果页用 `DiffView` 逐字符对照原文与输入，并以「完全正确 / 存在差异」徽标提示结论。

## 部分记忆

### 随机模式

- 显示抽取比例的数字输入框（0.01–1，步进 0.05）与 20% / 40% / 60% / 80% 四个快捷按钮，实时显示「当前将抽取 K 句（共 N 句）」。
- 点击「开始随机记忆」按比例随机抽取句子，抽取数量按
  `Math.max(1, Math.ceil(N * clamp(ratio, 0.01, 1)))` 计算，钳制顺序不可改。

### 指定模式

- 文章句子以行内可点击文本呈现，点击切换选中（选中时前缀 ✓）。
- 按住 Shift 点击支持范围选择；范围选择**只增不减**。
- 「开始指定记忆」按钮在未选中任何句子时禁用。

### 答题界面

进入答题后，页面按原文顺序展示完整文章，被选中的句子替换为行内输入框：

- 输入框高度随内容自动增高，长句不会被裁掉。
- 句子之间的原始标点与换行由 `ArticleFlow` + `extractDelimiters()` 原样还原。
- 提交后顶部横幅显示「N / M 正确」，全部正确时显示「🎉 全部正确！」。
- 批改后正确答案以绿色/红色标记显示，答错处附带「正确：……」提示；点击「重新作答」会清空整组空格（含已答对的），是"重做整组"而非"重做错题"。

## 指导记忆

- 配置页提供 AI 提示词模板（点击文本框即可复制）与 JSON 配置文件导入，格式为
  `{ "steps": [{ "hint": "提示文本", "sentenceIndices": [0, 1] }] }`。
- 答题页顶部显示当前步骤的提示文本，底部可「◀ / ▶」切换步骤、直接输入步号跳转、清除进度（需确认）或返回配置。
- 第一次点「🔍 检查」后才把目标句变为输入框；「提交检查」批改当前步骤并 Toast 回报答对/作答数量。
- 已完成作答的句子索引超出范围时会被过滤，防止配置损坏导致渲染崩溃。

## 状态机

```
menu ──► full ──► result ──► menu
 │
 ├──► partial-menu ──► partial-random ──► （原位批改 / 重新作答）──► menu
 │                 │
 │                 └──► partial-custom ──► （原位批改 / 重新作答）──► menu
 │
 └──► guided-menu ──► guided ──（步骤推进 / 回退）──► guided-menu
```

按 `Esc` 退一级：菜单层直接返回文章列表，其余模式返回菜单；指导记忆答题页返回配置页。
