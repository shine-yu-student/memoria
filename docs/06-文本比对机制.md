# 06 — 文本比对机制

## 文件说明

`src/utils/diff.tsx` — 基于 `diff` 库（npm: `diff`）进行字符级差异比较。

## 核心函数

### `computeDiff(original, userInput)`

```typescript
interface DiffSegment {
  text: string;
  type: 'correct' | 'missing' | 'extra';
}

function computeDiff(original: string, userInput: string): DiffSegment[]
```

使用 `diffChars()` 对原文和用户输入进行字符级 diff。返回分段列表，每段标记类型。

### 颜色标记

| 类型 | 含义 | 样式 |
|------|------|------|
| `correct` | 内容相同 | 绿色文字 |
| `missing` | 原文有 → 用户漏输入 | 橙色背景 + 橙色文字 |
| `extra` | 原文没有 → 用户多输入 | 红色文字 + 删除线 + 浅红背景 |

样式集中定义在 `src/utils/diff.tsx` 的 `styleMap` 中。

### 渲染组件

```tsx
<DiffView original="原文" userInput="用户输入" />
```

返回 `<span>` 元素列表，直接嵌入在文本流中。

## 判题逻辑

### 语文记忆

严格相等比对（字符串全等）：

```typescript
userInput.trim() === correct.trim()
```

### 英语记忆

忽略大小写 + 忽略首尾空白：

```typescript
userInput.trim().toLowerCase() === correct.trim().toLowerCase()
```

## 结果展示

当前版本的结果页与答题页只展示**正确数/总数**（如 `3/5 正确`），不计算百分比分数：

- **全篇记忆结果页**（`src/moderna/chinese/memory/FullResult.tsx`）：以「完全正确 / 存在差异」徽标给出结论，并用 `DiffView` 逐字符展示原文与用户输入的差异
- **部分记忆答题页**：批改后顶部显示 `N/M 正确` 概要；全部正确时显示"🎉 全部正确！"横幅
- 每个空格的判定与颜色标记见上文"颜色标记"一节
