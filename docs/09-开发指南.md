# 09 — 开发指南

## 环境要求

- Node.js >= 18
- npm >= 9

## 本地开发

```bash
# 安装依赖
cd memoria
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建
npm run build

# 预览生产构建
npm run preview
```

## 项目命令

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动 Vite 开发服务器（热更新） |
| `npm run build` | TypeScript 类型检查 + Vite 生产构建 |
| `npm run preview` | 本地预览构建产物 |

## 扩展指南

### 添加新的语言模块

1. 在 `src/moderna/` 下创建新目录（如 `japanese/`），按现有模块的样子实现列表 / 详情 / 记忆视图
2. 定义新的数据类型（在 `src/types/index.ts` 中添加）
3. 添加新的 storage 函数（在 `src/utils/storage.ts` 中添加）
4. 在 `src/moderna/shell/NavRail.tsx` 的 `ModernaTab` 与 `ITEMS` 中登记导航项
5. 在 `src/moderna/ModernaApp.tsx` 的 `TAB_ORDER` 与标签渲染分支中接入新模块
6. 文档同步更新到 `docs/` 目录

### 添加新的文章导入格式

文章正文目前在编辑页的文本框中手动输入/粘贴，词书与句书支持 JSON 批量导入。如需为文章支持文件格式（如 `.txt`），可在 `src/moderna/chinese/ArticleList.tsx` 或 `ArticleDetail.tsx` 中新增文件读取逻辑；文件读取可参考 `src/moderna/lib/download.ts`。

### 修改句子切分规则

编辑 `src/utils/splitter.ts` 中的 `DELIMITER_RE` 正则表达式。

### 修改比对逻辑

编辑 `src/utils/diff.tsx` 中的 `computeDiff()` 函数。

## 已知限制

- 所有数据存储在浏览器 localStorage 中，清除浏览器数据将丢失所有记忆内容
- 仅支持纯文本，不支持富文本或图片
- 不支持服务端同步或多设备同步
- 不适合存储超大量文章（localStorage 容量限制约 5-10MB）

## 构建部署

```bash
npm run build
# 输出目录: memoria/dist/
# 可将 dist/ 目录部署到任意静态文件服务器
```

## 代码规范

- 使用 TypeScript strict 模式
- 组件使用 `React.FC` 类型
- 所有数据操作走 `src/utils/storage.ts` 层；指导记忆进度走 `src/moderna/lib/guidedStorage.ts`
- **单一界面，单一套样式规范**（见 [11-界面层](./11-Moderna-界面.md)）：
  - 结构：功能目录放在 `src/moderna/` 下（`shell/`、`ui/`、`settings/`、`chinese/`、`english/` 等），业务模块内部可再分 `memory/` 等子目录
  - 样式：组件样式写在同名 `.module.css` 中并用 CSS Modules 引入；颜色、间距、圆角、字号、时序一律引用 `src/moderna/styles/tokens.css` 的 `--m-*` 令牌
  - 主题：`<html data-theme="light" | "dark">` 由 `src/moderna/lib/ThemeProvider.tsx` 写入，深色令牌在 `tokens.css` 的 `:root[data-theme="dark"]` 中覆盖
  - 动效：统一使用 framer-motion；时序与变体集中在 `src/moderna/motion/presets.ts` / `variants.ts`，组件通过 `useMotionKit()` 取用，以自动适配「减少动态效果」偏好
  - 内联 `style` 只用于无法用类表达的极小一次性数值（如 `height: '100%'`、`display: 'none'`）与错误边界兜底页；视觉样式不要写成内联 style，也不要新增全局 CSS 文件（`src/index.css` 只保留基础重置与 body 字体）
