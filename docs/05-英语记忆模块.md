```
│  📘 句书  M 本                                                │

```

- **页面头部**：`PageShell` 提供标题「词书 / 句书」、副标题（共 N 本词书 · M 本句书）与右侧的「🧠 选择内容」「＋ 词书」「＋ 句书」按钮。

- **分区**：📗 词书与 📘 句书各自有标题、数量与自适应网格。
- **卡片**：显示书名与条目数；非选择模式下鼠标悬停时右上角显示 🗑️ 删除按钮。
- **空状态**：没有任何书籍时显示引导新建的 `EmptyState`。

- **头部**：书名、条目数副标题，以及类型标签、批量导入与删除按钮。
- **新增条目**：英文、中文两个输入框 + 「＋ 添加词/句」按钮；两项都填写才允许添加，回车可直接提交。
- **条目紧凑展示**：
  - 每个条目以紧凑圆角卡片展示，宽度随内容自适应，可在一行内排列多个。

- **重命名按钮与从图片导入（OCR）功能已移除**：相关 UI、`src/utils/ocr.ts` 与 `tesseract.js` 依赖均已删除。

## 内容选择机制

选择机制整合在 BookList 列表页面中，没有独立的 selection 页面。

### 选择模式

1. 点击标题旁的「🧠 选择内容」进入选择模式（按钮变为「退出选择」）。
2. 选择模式下，每张书籍卡片的悬停位置显示全选框（`☐ / ☑`），点击即可整本选中或取消。
3. 页面底部出现吸底选择栏：显示「已选 N 项」，提供「取消」与「🧠 开始记忆」按钮（未选择任何内容时禁用）。
4. 开始记忆时，选中的词条与句条会被汇总成一个列表交给闪卡会话，因此**可同时从多本书中选择**。
5. 退出选择模式或删除书籍后，已失效的选择会被自动清理，避免「已选 N 项」虚高。

## 闪卡记忆系统

### 核心算法

```
初始状态：
  queue       = 打乱后的全部待测词条（Fisher-Yates）
  retestQueue = []    （答错后待复习的词条）
  answeredCount = 0   （已答题数，用于计算复习时机）

取下一个词（nextWord）：
  1. answeredCount++
  2. 检查 retestQueue 是否有到期的（dueAfter ≤ answeredCount）
     → 有：取出作为当前词
  3. 否则从 queue 取下一个
  4. queue 空但 retestQueue 还有 → 取 dueAfter 最小的一条
  5. 两者皆空 → 进入「全部完成」页
```

答错的词在 3–5 张后复现（`dueAfter = answeredCount + 3 + floor(random * 3)`）；
`progress.done` 只计**首次答对**，重测答对不增加，因此进度条可能停在 100% 以下。

### 答题界面

- **顶部状态栏**：已完成 / 总数、错误次数、实时用时 `MM:SS`，右侧「结束」按钮。
- **进度条**：按首次答对比例推进。
- **卡片**：中央显示中文含义；重测中的条目带「🔁 复习」标签。
- **输入框**：用户输入对应英文，回车或点击「提交」作答。
- **答错处理**：展开正确答案并要求重新输入；再次输错则错误次数累加，输对后把该条目送入 retest 队列。
- **完成页**：全部完成后显示「🎉 全部完成！」与总用时，点击「查看结果」进入结果页。

### 结果页面

- **总数**：本次记忆的条目总数。
- **首次答对**：首次作答即正确的数量。
- **答错次数**：累计答错次数。
- **用时**：记忆总耗时（完成后冻结）。
- **错词列表**：可展开查看曾答错的条目及各自错误次数（同一条目可能出现多次）。

### 比对规则

```typescript
userInput.trim().toLowerCase() === correct.trim().toLowerCase()
```

- 忽略首尾空白。
- 忽略大小写差异。
