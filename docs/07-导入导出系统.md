# 07 — 导入导出系统

## 文件说明

| 文件 | 职责 |
|------|------|
| `src/moderna/settings/DataSection.tsx` | 全量导入导出 UI（设置 → 数据） |
| `src/moderna/lib/download.ts` | 浏览器端 JSON 下载 / 文件读取 |
| `src/utils/storage.ts` | 存储层（含全量导入导出的合并逻辑） |

## 入口

全量导入导出位于**设置面板**的「数据」分类：点击顶栏右侧的 ⚙️ 打开设置弹窗，切换到「数据」即可导出全部数据或从备份文件恢复。

单个资源的导入导出分布在各业务页面：

- **文章编辑页**：标题右侧的「⬇️ 导出」按钮导出当前文章。
- **词书/句书详情页**：「📋 从 JSON 导入」把 JSON 中的条目追加到当前书（不覆盖已有内容）。

## JSON 序列化

### 单资源导出

每篇文章都可单独导出为 JSON：

```json
{
  "id": "abc123...",
  "title": "文章标题",
  "content": "全文内容……",
  "sentences": ["句子1", "句子2"],
  "createdAt": 1700000000000
}
```

文章编辑页调用 `downloadJSON(data, filename)`（`src/moderna/lib/download.ts`）触发下载，文件名取当前标题。

### 全量备份格式

```typescript
interface MemoriaData {
  version: 1;
  articles: Article[];
  wordBooks: WordBook[];
  sentenceBooks: SentenceBook[];
  exportedAt: number;
}
```

全量导入采用**按 id 合并模式**（非覆盖）：
- **文章**：按 id 匹配，同 id 已存在则跳过（保留原有）。
- **词书/句书**：按 id 匹配，同 id 合并条目（按 `english` 字段去重）。
- **缺失 id** 的文章/词书/句书导入时自动生成新 id 后追加，不会静默丢弃数据。
- 导入完成后以 Toast 回报统计（新增 / 合并 / 跳过）。

## 文件处理

### 下载

`src/moderna/lib/download.ts` 的 `downloadJSON()` 使用 `Blob + URL.createObjectURL` 实现浏览器端下载：

```typescript
function downloadJSON(data: unknown, filename: string) {
  const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  // 延迟 revoke：立即 revoke 时部分浏览器（如 Firefox）下载尚未开始
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

### 上传

同文件的 `readJSONFile()` 使用 `FileReader` 读取文件内容并解析 JSON，解析失败时抛出「JSON 解析失败」：

```typescript
function readJSONFile(file: File): Promise<unknown> {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.onload = () => {
      try {
        resolve(JSON.parse(reader.result as string));
      } catch {
        reject(new Error('JSON 解析失败'));
      }
    };
    reader.onerror = () => reject(new Error('文件读取失败'));
    reader.readAsText(file);
  });
}
```

## 错误处理

- JSON 解析失败 → Toast 提示「JSON 解析失败」。
- 备份文件缺少 `version` 字段 → Toast 提示「无效的备份文件格式」，拒绝导入。
- 词书/句书批量导入未识别到有效条目 → Toast 提示「未识别到有效条目」。
- 文件读取失败 → 捕获异常并以 Toast 提示。
- 导入结果不会静默：DataSection 会回报新增、合并、跳过的数量。
