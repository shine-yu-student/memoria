# 02 — 架构设计

## 系统架构

Memoria 采用**单页应用（SPA）**架构，所有数据存储在客户端浏览器中，无需后端服务。

│              ├── Shell                                           │

## 分层职责

| 目录 | 职责 |
|------|------|
| `shell/` | 全局框架：`Shell`（CSS Grid 三区）、`TopBar`、`NavRail`、`PageShell` |
| `ui/` | 无业务的基础原语：按钮、弹窗、确认框、Toast、表单控件、进度条、空状态等 |
| `motion/` | 动效时序与变体（`presets.ts` / `variants.ts`）、动效强度根节点（`MotionRoot`）、取用与降级（`useMotionKit`） |
| `settings/` | 设置上下文与设置面板：外观分区、数据分区 |
| `lib/` | 主题 Provider、下载/文件读取、本地设置、媒体查询、指导记忆存储与校验 |
| `chinese/` | 文章业务模块，含 `memory/` 记忆子目录 |
| `english/` | 词书/句书业务模块，含 `memory/` 闪卡子目录 |
| `src/types`、`src/utils` | 全应用共享的数据模型、存储、句子切分与差异比对 |

## 布局说明

### 全局框架

页面框架由 `src/moderna/shell/Shell.module.css` 的 CSS Grid 定义（`height: 100vh`）：

- **两列**：`var(--m-rail-w)`（72px）导航导轨 + `1fr` 主区
- **两行**：`var(--m-topbar-h)`（60px）顶栏 + `1fr` 内容区
- **区域**：`"topbar topbar" / "rail main"`（顶栏横跨两列）

- **顶栏 (TopBar)**：占据整行，`position: sticky`（不用 fixed：framer-motion 的 layout 投影在 fixed 祖先下会测量错误），包含品牌名「Memoria / 记忆助手」、浅色/深色切换按钮与设置按钮。
- **导航导轨 (NavRail)**：左侧常驻的 72px 图标导轨，显示「语文」「英语」两项，图标在上、文字在下；激活项的背景指示条用 framer-motion 的 `layoutId` 在两项目间平滑滑动。图标常显，**没有 hover 展开**，因此没有防抖，也没有展开宽度变化。
- **主区 (main)**：`overflow: hidden`，承载当前标签页；标签切换由 `ModernaApp` 的 `AnimatePresence`（`tab` 变体）完成。
- **页面容器 (PageShell)**：常规页面为「头部 + 滚动内容区」——头部含标题、可选副标题与右侧操作区，内容区 `overflow-y: auto`；记忆类页面使用 `bare` 模式，不渲染头部，整页滚动。

### 设置面板

设置面板 (`SettingsPanel`) 是一个 `Modal`（`wide`）：左侧为「外观 / 数据」分类列表，右侧渲染对应分区。关闭方式为点击遮罩、右上角 ✕ 或按 `Esc`。Toast 与确认框同样由 `ModernaApp` 层的 Provider 提供，并 portal 到 `document.body`。
